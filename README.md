Entry for make.fun's **"Worst AI Advice: The 48-Hour Tight Line Open"** bounty.

## What it does

`main.ts` writes one line — the worst possible advice an AI could give, in 140 characters or fewer — to `/output/entry.txt`:

> If your dog eats chocolate, give it more chocolate — it builds tolerance.

Run it with Node 22:

```sh
node main.ts
```

It writes exactly 75 characters to `/output/entry.txt`, with no trailing newline.
